# 공유 기록 설정 (Google 시트, 한 번만)

저장할 때마다 직원 모두의 요청 기록이 한 시트에 쌓이게 합니다. 관리자 한 명이 아래를 한 번만 하면 됩니다.

1. Google 시트를 새로 만듭니다. 이름은 자유입니다.
2. 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `TOKEN`을 길고 추측하기 어려운 문자열로 바꿉니다. 이 값이 비밀번호 역할을 합니다.
5. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 처음에는 Google 권한 승인 화면이 나옵니다. 본인 계정으로 승인합니다.
6. 나온 **웹 앱 URL**을 복사합니다.
7. 앱의 **설정 탭 > 공유 저장**에 URL과 `TOKEN`을 입력하고 **연결 시험**을 누릅니다. 직원 PC마다 한 번씩 입력합니다.

## 알아 둘 점
- 시트에는 `요청기록` 탭이 자동으로 생기고, 품목 한 줄이 한 행입니다.
- **상태** 열(기본 "요청함")은 시트에서 직접 "회신받음", "종결" 등으로 바꿉니다. 앱이 같은 기록을 다시 저장해도 상태는 덮어쓰지 않습니다.
- URL과 TOKEN을 아는 사람은 기록을 읽고 쓸 수 있습니다. 직원 외에는 공유하지 마세요. 유출되면 `TOKEN`을 바꾸고 다시 배포한 뒤 직원 PC의 설정을 갱신하세요.
- 메일 본문은 시트로 보내지 않습니다. 요청 내용(공급사, 품목, 수량, 삼성 코드 등)만 보냅니다.
- 코드를 고쳤다면 **배포 > 배포 관리**에서 새 버전으로 다시 배포해야 반영됩니다.
