# 견적요청 메일 작성기 (RFQ Mailer)

공급사에 보내는 견적요청 메일을 빠뜨린 정보 없이 작성하는 단일 HTML 웹앱입니다. 자체 서버는 없고, 입력한 내용은 사용하는 브라우저(localStorage)에 저장됩니다. 설정 탭에서 공유 저장(Google Apps Script 주소)을 켠 경우에만 저장 시 요청 내용(메일 본문 제외)이 그 주소로 전송됩니다. 설정은 `apps-script/SETUP.md`를 참고하세요.

- 필수 정보(사용 부서, 자재 코드, 공급사 연락처 등)가 비면 복사·저장이 막힙니다. 모르는 값은 "미확인"으로 표시합니다.
- 품목별 카탈로그 등재 여부, 첨부 자료 체크, 회신 확인일, 전화 스크립트와 독촉 메일 초안을 만듭니다.
- 한국어/베트남어 화면. 메일 본문은 한국어입니다.
- 회사명, 서명, 공급사 주소록은 설정 탭에서 각자 입력합니다. 코드에는 들어 있지 않습니다.

사용: `index.html`을 브라우저에서 열거나 GitHub Pages 주소로 접속합니다.
